01適用・運営者

  1. 本ポリシーは、SAYU（以下「運営者」といいます）が提供する「工学院大学GPA計算機」（以下「本サービス」といいます）における利用者情報の取扱いに適用されます。
  2. 運営者は、個人情報の保護に関する法律その他適用される法令を遵守し、本ポリシーに従って利用者情報を取り扱います。
  3. 本サービスは、工学院大学または同大学の関連法人が運営、承認または提供する公式サービスではありません。

02取得・処理する情報

認証・アカウント情報

  • 工学院大学Googleアカウントのメールアドレス
  • GoogleおよびSupabaseが発行する利用者識別子
  • Google認証により提供される基本プロフィール情報
  • アクセストークン、リフレッシュトークン、認証状態および認証日時
  • 利用規約および本ポリシーへの同意版ならびに同意日時

運営者は、Googleアカウントのパスワードを取得しません。

成績PDF・成績情報

  • PDFファイル本体、ファイル名、SHA-256ハッシュ値、発行日時、作成日時、作成ソフトおよびファイル構造に関する情報
  • 学籍番号、学年、学部、学科その他の所属情報
  • 科目名、科目ID、年度、学期、評定、単位数および履修状況
  • GPA、累積GPA推移、成績内訳、履修中科目および試算に用いる情報
  • シラバスから一意に特定できない科目、正規化した科目名および利用者が選択した単位数

サービス利用情報

  • ランキングに表示するニックネーム、公開用識別子、順位および登録更新日時
  • 受付用識別子、受付チケット、処理状態、処理日時、エラーコード、パーサーのバージョンおよび更新回数
  • IPアドレス、User-Agent、参照元、アクセス日時、リクエスト情報その他の通信記録
  • 問い合わせ時に利用者が送信する内容および連絡に必要な情報

03取得方法

  1. 運営者は、Google OAuthおよびSupabase Authを通じて認証・アカウント情報を取得します。
  2. 運営者は、利用者が選択した成績PDF、入力したニックネーム、選択した単位数その他利用者が本サービスへ提供する情報を取得します。
  3. 運営者は、本サービスの利用に伴い、利用端末、ブラウザ、サーバーおよび外部サービスから通信記録、処理記録および識別子を自動的に取得または生成します。
  4. 利用者の端末内だけで処理する情報は、サーバーへの送信を伴わない限り、運営者がサーバー上で取得する情報には含まれません。

04利用目的

運営者は、取得した情報を次の目的で利用します。

  • 大学アカウントによる認証、利用資格の確認およびセッションの維持
  • ニックネームとGoogleアカウントの表示名または学籍番号との照合、および不適切なニックネームの登録防止
  • 成績PDFの真正性、形式、発行日時およびログイン中の大学アカウントとの対応関係の検証
  • 科目、評定、年度、学期および単位数の判定ならびにGPA計算
  • 計算結果、成績内訳、GPA推移、予測、再履修・リピート試算および計算履歴の表示
  • ランキング情報の登録、更新、表示、検索、絞り込みおよび重複登録の防止
  • 科目別成績統計ならびに全体・学部・学科別のGPA統計の作成および表示
  • シラバス未登録科目、表記揺れおよび単位数判定の精度改善
  • 受付処理、利用回数制限、複数タブからの処理、キャッシュおよびエラー復旧の管理
  • 不正利用の検知および防止、アクセス制御、障害調査、セキュリティ確保ならびにサービスの保守
  • 問い合わせ、開示等の請求および利用者からの申出への対応
  • 個人を直接識別しない集計情報を用いた利用状況の把握および機能改善

運営者は、法令により認められる場合を除き、利用目的を超えて利用者情報を取り扱いません。利用目的を変更する場合は、変更前の目的と合理的な関連性を有する範囲で行い、本サービス上で公表します。

05端末内の処理

  1. 発行から31日以上経過した成績PDFおよび未対応の学籍番号を含む成績PDFは、原則としてPDF.jsを使用して利用者のブラウザ内で計算します。
  2. 前項の計算では、PDF本体およびGPA計算のために抽出した成績情報をSupabaseへ送信せず、ランキングおよび成績統計へ登録しません。
  3. 端末内で生成した計算結果、計算履歴、単位数設定その他の情報は、ブラウザの保存領域に保存される場合があります。

06サーバー処理

  1. 対応する新しい成績PDFは、受付処理の後、検証およびGPA計算のためSupabase Edge Functionsへ送信されます。
  2. PDF本体はリクエスト処理中に使用されますが、本サービスのデータベースまたはSupabase Storageへ永続的に保存されません。
  3. ログイン中の大学アカウントと成績PDF内の学籍番号が一致し、発行から31日未満であるなど所定の条件を満たす場合、計算完了時にランキングおよび成績統計の情報を自動的に登録または更新します。
  4. ランキングには、公開用識別子、GPA、ニックネーム、学部、学科および学年を登録します。照合および重複防止のため、認証ユーザー識別子、固定saltを用いた学籍番号ハッシュ、PDFハッシュ、更新日時その他の非公開情報を処理します。
  5. 成績統計には、公開用識別子、科目IDまたは科目名、年度、学期、評定その他集計に必要な情報を登録します。GPA推移の集計には、学部、学科、学年進行段階および累積GPAを使用します。
  6. 学籍番号ハッシュおよび公開用識別子は、学籍番号そのものを表示しないための識別子ですが、認証情報等との照合が可能な状態にあるため、匿名加工情報としては取り扱いません。

07ランキング・統計

  1. 認証済みの利用者に対し、ランキング上のニックネーム、GPA、順位、学部、学科および学年を表示し、条件による検索、絞り込みおよび分布表示に使用します。
  2. ランキングへの初回登録時には「guest」を表示し、利用者が設定した場合は当該ニックネームへ更新します。
  3. 科目別成績分布および全体・学部・学科別のGPA推移は集計値として表示します。
  4. ランキングおよび統計は学籍番号そのものを表示しません。ただし、所属、学年、GPA、ニックネーム、少人数の集計値その他の情報を組み合わせることにより、特定の利用者または成績が推測される可能性があります。
  5. 運営者は、ランキングおよび統計に使用する情報を広告配信、信用評価、採用選考その他本サービスの提供と関係のない目的に使用しません。

08ブラウザ保存

本サービスは、localStorageまたはsessionStorageに次の情報を保存します。

  • Supabase Authのログインセッション、認証状態および利用者識別子
  • PDFファイル名、PDFハッシュ、学籍番号およびPDF発行日時
  • GPA、単位数、科目名、評定、年度、学期、履修中科目、予測情報および計算履歴
  • ランキング公開用識別子、ニックネームおよび利用者が選択した単位数
  • 受付用識別子、一時的な受付情報、ランキング、成績統計、GPA平均値等のキャッシュおよび画面設定
  • 同意した利用規約および本ポリシーの版ならびに同意日時

PDF本体はブラウザの計算履歴へ保存しません。ログアウトしても、計算履歴、ニックネーム、単位数設定その他ブラウザに保存された情報は自動的に削除されません。

09Cookie・アクセスログ

  1. 本サービスおよび利用する外部サービスは、認証状態の維持、セキュリティ確保、通信処理および機能提供のため、Cookie、Web Storageその他の端末識別技術を使用する場合があります。
  2. サイト配信、認証、APIおよびサーバー処理を提供する事業者は、IPアドレス、User-Agent、アクセス日時、参照元、リクエスト先、応答状況その他のアクセスログを記録する場合があります。
  3. 本サービスは、行動ターゲティング広告を目的として成績情報を使用しません。

10保存期間

PDF本体
Edge Functionsのリクエスト処理中だけ使用し、本サービスのデータベースまたはSupabase Storageへ意図的に保存しません。
ブラウザの計算履歴
利用者が本サービスの履歴削除機能またはブラウザのサイトデータ削除機能を使用するまで保存されます。一定期間後に自動表示の対象外となる場合でも、保存データが同時に削除されるとは限りません。
ランキング・統計情報
削除申請、サービスの終了または利用目的上不要となるまで保存します。現時点では一律の自動削除期限を設けていません。
受付・処理情報
処理の完了、失敗、期限切れの管理、不正利用防止および障害調査に必要な期間保存し、システムの清掃処理により削除します。
キャッシュ
情報の種類に応じた有効期間、ブラウザのタブセッション終了時またはサイトデータの削除時まで保存します。
同意記録
同じ利用者が新しい版へ同意した場合に上書きされ、ブラウザのサイトデータが削除されるまで保存されます。Google認証前の一時的な同意情報は、同一タブ内に最長5分間保存します。
アクセスログ
各外部サービス提供者のセキュリティ、障害対応および保存方針に従って保持されます。

  3. 運営者は、本サービスの構成または委託先を変更した場合、必要に応じて本ポリシーの外部サービスに関する記載を更新します。

  1. 本サービスは、認証に必要な範囲でGoogleアカウントの情報へアクセスします。

  3. 情報漏えい、不正アクセス、改ざんまたは滅失が発生し、利用者への通知が必要と判断した場合は、法令に従い必要な対応を行います。
