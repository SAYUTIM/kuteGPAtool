基本的な使い方

  1. キューポートから成績PDFを保存する

    キューポート > 成績メニュー > 4 成績照会 のページにある右上の「PDF」ボタンから自分の成績PDFをダウンロードします。

  2. GPA計算機でPDFを選択する

    トップページの「成績PDFを選択」からファイルを読み込みます。

  3. 計算結果を確認する

    計算が終了すると、通算GPA、GPT、取得単位、評定内訳、GPA推移などを確認できます。

GPA計算機を開く

GPAとGPT

　GPAは、履修した科目の成績をGrade Pointに置き換えて平均した指標です。本サービスでは、GPAの計算過程を確認しやすくするため、各科目の「単位数 × Grade Point」を合計したGPTも表示します。GPAの利用条件や選考基準は制度ごとに異なるため、履修・進級・奨学金・進学などの判断では大学の最新の公式情報も確認してください。

　評定にはA+, A, B, C, D, Fの6段階があります。各科目の評定は以下の表に対応するGrade Pointに置き換え、単位数を掛けてGPAやGPTを計算します。

評定とGrade Pointの対応
評定Grade Point
A+4.00
A3.67
B3.00
C2.00
D1.00
F0.00

GPTとは

　GPT（Grade Point Total）は、GPA計算に使う各科目の「単位数 × Grade Point」を合計した値です。

GPT = ∑ ( 単位数 × Grade Point )

　例えば、2単位のA+ と 1.5単位のA と 1単位のF がある場合、GPTは 2×4.00 + 1.5×3.67 + 1×0.00 = 13.505 です。

　GPTは総単位数とは異なり、同じ単位数でも評定が高いほど大きくなります。本サービスではGPAとあわせて計算結果やランキングの確認に使用します。

GPAとは

　GPA（Grade Point Average）はGPTをGPA算入単位数で割った値です。小数点以下第3位を四捨五入し、4.00~0.00の範囲で表示されます。

GPA = GPT GPA算入単位数

　上の例ではGPA算入単位数が4.5単位なので、13.505 ÷ 4.5 ≒ 3.001 となり、GPAは 3.00 になります。

Fと「取得単位」の扱い

　GPA計算の対象になっているF科目はGrade Pointが0ですが、その科目の単位数はGPAの分母に入ります。一方、結果画面の「取得単位」はFを除いて集計します。そのため、GPA算入単位数と取得単位数は同じとは限りません。

GPA / GPT の解析範囲

　成績PDFは通常成績を上から読み取り、「教職課程科目」または「数理・データサイエンス・AI（リテラシー）」の見出しが最初に現れた時点でGPA / GPTの解析を終了します。見出し自体とそれ以降の科目は計算対象外です。どちらの見出しもない場合は「単位修得状況表」を成績欄の終端として扱います。


　本サービスの表示値は、読み込んだ成績PDFをもとにその時点で計算した値です。大学が公式に提示するGPAや各制度で使用される値と確認時期が異なる場合があるため、重要な判断では公式情報と照合してください。

再履修・リピート

　同一科目として判定された履修歴が複数ある場合は、A+ > A > B > C > D > F の順で最も高い評定だけをGPA計算に使います。
　たとえば、最初に評定Fだった科目を再履修して評定Bになった場合は、評定Bを使ってGPAを計算します。その時、同じ科目であれば、単位数は1科目分のみが計算に含まれます。

再履修・リピートのシミュレーション

　結果画面の「再履修・リピート」では、科目と評定を選んでGPAの変化を試算できます。
　検索のサジェストには上から履修済みの中で低い科目から昇順で表示されます。また、その後ろには現在履修中または履修予定の科目が表示されます。任意の科目を検索して選択することもできます。

ランキング

　ランキングページでは、本サービスに登録された対象者と自分の順位、成績分布のグラフ、平均値・最頻値・中央値などを確認できます。GPAとGPTで基準を切り替えられ、絞り込み条件を変更すると、比較対象の人数や順位も変わります。

GPAを基準にする場合

　GPAが高い順に並び、GPAが同じ場合はGPTが高い人を先に表示します。 GPAとGPTがともに同じ場合は同順位です。

GPTを基準にする場合

　GPTが高い順に並びます。GPTが同じ人は同順位で、同じGPTの中ではGPAが高い人を先に表示します。

ランキングへの登録・更新

　大学アカウントでログインし、PDF内の学籍番号が一致した状態で、登録対象のPDFを計算するとランキングと科目別成績統計が登録または更新されます。
　初回のニックネームは「guest」で、8文字以内で任意のニックネームに変更可能です。

科目別成績統計

　科目ごとの履修者数、平均GPA、単位取得率、成績分布などを確認でき、学部・学科・学期による絞り込みもできます。

表示主な基準
科目を探す科目一覧・検索条件にあった科目を表示します。
楽単科目50人以上のデータがある科目を対象に、A+ / A の割合をもとに降順で並べます。
落単科目50人以上のデータがある科目を対象に、D / F の割合をもとに降順で並べます。
人気科目履修者数をもとに降順で並べます。

　楽単・落単ランキングは、単純な割合順ではありません。参加者が少ない科目が偶然高い割合になったことで上位に表示されにくいよう、95% Wilson信頼区間の下限を用いて補正しています。

95% Wilson下限とは

　割合には、履修者数が少ないほど結果が偶然に左右されやすいという問題があります。95% Wilson下限は、そのばらつきを考慮して、観測された割合を保守的に評価するための値です。楽単科目ではA+・Aの割合、落単科目ではD・Fの割合について、次の式で下限値を計算します。

Wilson下限 L = p̂ + z2 2n − z p̂(1−p̂) n + z2 4n2 1 + z2 n

式に使う記号

記号意味このランキングで入る値
LWilson信頼区間の下限補正後の割合。順位を決める値です。
x対象の評定だった人数楽単ではA+・A、落単ではD・Fだった人数です。
n履修者数その科目について集計された全人数です。
p̂補正前の割合x ÷ n。たとえば45人÷50人なら0.90です。
z信頼水準に対応する値95%では常に 1.96 を使います。

よくある質問

GPTは総単位数と同じですか？

違います。総単位数は単位数の合計ですが、GPTはGPA計算に使う各科目の「単位数 × Grade Point」を合計した値です。同じ単位数でも評定が違えばGPTは変わります。

Fを取るとGPAはどうなりますか？

FのGrade Pointは0です。GPTには加点されませんが、GPA計算の対象になっているF科目の単位数はGPA算入単位数に含まれるため、GPAを下げる方向に働きます。

再履修したらFと新しい評定の両方がGPAに入りますか？

同一科目として判定された場合は、最も高い評定だけをGPA計算に使います。

GPTが「—」と表示されるのはなぜですか？

GPT機能の追加前(2026/09/15より前)に登録されたデータなど、GPTがまだ保存されていないランキング行があるためです。

古い成績PDFでもランキング登録できますか？

発行から31日以上経過したPDFは、原則としてランキングや科目別成績統計には登録されません。

アップロードしたPDFは保存されますか？

サーバーで計算するPDFは処理中に使用しますが、PDFファイルを計算後に本サービスのデータベースやファイル保存領域へ保存することはありません。
