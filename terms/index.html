01適用

  1. 本規約は、SAYU（以下「運営者」といいます）が提供する「工学院大学GPA計算機」（以下「本サービス」といいます）の利用に関する運営者と利用者との間の一切の関係に適用されます。
  2. 本サービス上で個別に掲示する利用条件、注意事項その他の定めは、その名称を問わず本規約の一部を構成します。
  3. 本規約と前項の定めが異なる場合は、当該定めに別段の記載がない限り、本規約が優先して適用されます。

02定義

利用者
本規約に同意し、本サービスを利用する者をいいます。
大学アカウント
工学院大学から利用者本人に付与されたGoogleアカウントをいいます。
成績PDF
工学院大学の成績情報を含み、本サービスの計算対象として利用者が選択するPDFファイルをいいます。
登録情報
認証情報、成績情報、ニックネーム、ランキング情報、統計用情報その他本サービスの利用に伴い登録または生成される情報をいいます。

03同意・規約の優先

  1. 利用者は、本規約およびプライバシーポリシーに同意した場合に限り、認証を要する機能を利用できます。
  2. 未成年者が本サービスを利用する場合は、法定代理人の同意その他法令上必要な手続を行ったうえで利用するものとします。
  3. 利用者が本規約の変更後に本サービスを利用した場合、法令上別途の同意が必要な場合を除き、変更後の規約に同意したものとみなします。

04利用資格・認証

  1. 大学アカウントによる認証が必要な機能は、当該アカウントを正当に保有する本人のみ利用できます。
  2. 利用者は、自己の大学アカウントおよび自己に発行された成績PDFのみを使用し、認証情報を第三者に貸与、譲渡、共有または使用させてはなりません。
  3. 利用者は、大学アカウントの管理について責任を負い、認証情報の漏えいまたは第三者による利用を認識した場合は、速やかに大学所定の手続を行うものとします。
  4. 大学アカウントの停止、削除、利用資格の喪失その他認証基盤の事情により、本サービスの全部または一部を利用できない場合があります。

05本サービスの内容

  1. 本サービスは、成績PDFに基づくGPA計算、GPA推移および成績内訳の表示、再履修・リピートの試算、GPAランキングならびに科目別成績統計を提供します。
  2. 本サービスは工学院大学または同大学の関連法人が運営、承認または提供する公式サービスではありません。
  3. 本サービスに表示される計算結果、ランキング、統計、予測および奨学金に関する情報は参考情報であり、大学の成績認定、進級、卒業、履修または奨学金の決定を構成しません。
  4. 運営者は、利用状況、技術上の必要、法令または外部サービスの仕様に応じて、本サービスの機能、対象、提供方法および利用条件を変更できます。

06GPA計算

  1. 本サービスは、成績PDFから抽出した情報、大学が公開する資料、独自に整備したシラバスデータその他の情報を用いてGPAを計算します。
  2. 科目名、年度、学期、評定、単位数、再履修の取扱い、所属情報、PDFの形式または参照データの不備等により、計算結果が大学の公式な値と異なる場合があります。
  3. 単位数を一意に判定できない場合、利用者が選択した単位数を計算に使用します。利用者は、大学が公開する情報と照合して正しい値を選択するものとします。
  4. 発行から31日以上経過した成績PDFまたは未対応の学籍番号を含む成績PDFは、原則として利用者の端末内で計算され、ランキングおよび成績統計へ登録されません。
  5. 対応する新しい成績PDFは、検証および計算のためサーバーへ送信されます。PDF本体は処理中に使用されますが、本サービスのデータベースまたはファイルストレージへ永続的に保存されません。
  6. 利用者は、重要な判断を行う前に、計算に使用された科目、評定および単位数を大学の公式情報と照合するものとします。

07ランキング・統計

  1. ログイン中の大学アカウントと成績PDF内の学籍番号が一致し、発行から31日未満であるなど所定の条件を満たす成績PDFをサーバーで計算した場合、計算完了時にランキングおよび成績統計の情報が自動的に登録または更新されます。
  2. ランキングへの初回登録時には「guest」がニックネームとして設定されます。利用者は、本サービスが定める文字数その他の条件に従いニックネームを変更できます。
  3. ランキングでは、ニックネーム、GPA、順位、学部、学科および学年を、認証済みの利用者に表示し、絞り込み、分布表示および集計に使用します。
  4. 科目別成績統計および全体・学部・学科別のGPA推移は、利用者の情報を集計して表示します。
  5. 端末内だけで行われた計算、キャッシュから再表示された結果その他登録条件を満たさない処理は、ランキングおよび成績統計へ反映されません。
  6. 利用者は、所属等による絞り込みその他の情報との組合せにより、ランキング上の利用者が推測される可能性があることを了承するものとします。

  2. 運営者は、ニックネームが本規約に違反し、または本サービスの運営上不適切であると合理的に判断した場合、事前の通知なく当該ニックネームを変更、初期化または非表示にできます。
  3. ニックネームの設定によって第三者との間に紛争が生じた場合、利用者は自己の責任と費用でこれを解決するものとします。
